#### guardscope

| 항목 | 기록 |
|---|---|
| 발표일 · 자료 유형 | 2026-11-11, arXiv 프리프린트 v1. 2026-11-16 확인. |
| 핵심 발견 | 게이트웨이의 기록만으로는 에이전트의 모든 실행 경로를 확인하기 어렵습니다. 연구진은 도구 호출이나 직접 네트워크 연결을 포함한 15개 경로를 정의하고, 제어 지점의 로그와 커널 관측을 대조하는 방법을 제시했습니다. |
| 연구의 한계 | 15개 경로 중 4개를 기준 워크로드에서 실측했습니다. 제어 지점이 호출을 검사했다는 기록은 정책 결정의 정확성까지 입증하지 않습니다. 커널 관측에는 페이로드 내용이 포함되지 않습니다. |
| 랩 적용 · 로컬 검증 | [07 AI Agent Security](../../labs/role-groups/04-security-trust/experiments/ai-agent-security/README.md#2026-11-16-연구-후속-검증)에서 게이트의 감사 기록과 루프백 서버의 요청을 대조했습니다. 정상 호출은 기록과 수신이 1건씩 발생하고, 거부된 호출은 서버에 도달하지 않아야 합니다. 게이트 밖 직접 호출은 수신 기록만 남기는 대조군입니다. |
| 원문 · 코드 | [guardscope 논문](https://arxiv.org/abs/2611.15223) · [연구 코드](https://github.com/VulcanLab/guardscope) |

## 컨소시엄

표준화 단체·산업 협의체의 규격, 작업 초안, 상호운용성 자료입니다. 단체명, 문서 번호, 버전과 상태(초안·발행 규격·구현 보고서), 확인한 조항을 기록합니다. 상호운용성을 주장하는 자료는 참여 구현과 시험 조건을 함께 남깁니다.

공식 원문을 확보한 첫 항목부터 추가합니다. 검토 주제는 멀티벤더 EVPN의 경계 동작과 AIDC 패브릭의 혼잡·텔레메트리입니다.

## 새 항목 기록 양식

| 필드 | 기록 내용 |
|---|---|
| 제목 · 분류 | 같은 주제의 기존 항목이 있으면 해당 항목에 이어서 기록 |
| 원문 · 날짜 | 공식 URL, 발표자 또는 기관, 발행·발표일, 실제 확인일 |
| 확인 범위 | 프로그램 안내 / 원문 본문 / 발표 자료 / 재확인 대기. 필요한 경우 페이지·시각·버전 기재 |
| 확인한 내용 · 해석 | 출처가 설명한 내용과 내가 세운 실험 가설을 나눠 기록 |
| 연결 · 다음 검증 | 담당 랩과 기존 실험 또는 후보 링크, 비교할 입력·관측값·판정 조건 |
| 실험 상태 | 후보 / 설계 / 로컬 검증 / 런타임 검증. 실행한 환경·입력과 증적을 함께 기록 |

공식 프로그램에 소개된 세션은 발표 본문이 확보되기 전까지 그 범위로 기록합니다. 공개 기록은 가상 환경과 공개 가능한 자료만 사용합니다.
