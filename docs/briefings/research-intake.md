# 브리핑·컨소시엄·세미나 기록

자료는 **어디에서 나온 정보인지**에 따라 아래 세 분류 중 하나에 기록합니다. 여러 분류에 걸친 주제는 원문을 가장 잘 설명하는 곳에 한 번 기록하고 관련 항목을 연결합니다. 운영 질문이 생기면 [실험 후보](../experiment-backlog.md) 또는 해당 랩의 기존 실험을 연결합니다.

## 브리핑

뉴스, 릴리스 노트, 벤더 권고처럼 정기적으로 수집한 항목입니다. 후속 보도는 기존 사건에 연결하고, 기사 발행일과 사건 발생일을 구분합니다.

- [누적 브리핑](cumulative-summary.md)
- [후속 정리](latest-updates.md)
- [브리핑 출처 대장](source-register.md)

## 컨소시엄

표준화 단체·산업 협의체의 규격, 작업 초안, 상호운용성 자료입니다. 단체명, 문서 번호, 버전과 상태(초안·발행 규격·구현 보고서), 확인한 조항을 기록합니다. 상호운용성을 주장하는 자료는 참여 구현과 시험 조건을 함께 남깁니다.

공식 원문을 확보한 첫 항목부터 추가합니다. 검토 주제는 멀티벤더 EVPN의 경계 동작과 AIDC 패브릭의 혼잡·텔레메트리입니다.

## 세미나

컨퍼런스, 웨비나, 기술 발표를 포함합니다. 행사명·세션명·발표자·개최일과 공식 URL을 기록하고, 발표 자료를 확보한 경우 슬라이드 페이지나 영상 시각을 남깁니다.

| 기존 항목 | 현재 기록에서 확인 가능한 범위 | 연결 |
|---|---|---|
| Cisco Live 2026 | 기존 노트에 공식 PDF와 페이지 범위가 기록됨 | [패브릭 연결·변경 검증](conference-notes.md) |
| DATA CENTER KOREA 2026 | 기존 노트는 사전 프로그램 기반. 발표 본문 확인 대기 | [선별 세션](conference-notes.md#데이터센터코리아-2026--사후에-볼-자료-선별) |

## 새 항목 기록 양식

| 필드 | 기록 내용 |
|---|---|
| 제목 · 분류 | 같은 주제의 기존 항목이 있으면 해당 항목에 이어서 기록 |
| 원문 · 날짜 | 공식 URL, 발표자 또는 기관, 발행·발표일, 실제 확인일 |
| 확인 범위 | 프로그램 안내 / 원문 본문 / 발표 자료 / 재확인 대기. 필요한 경우 페이지·시각·버전 기재 |
| 확인한 내용 · 해석 | 출처가 설명한 내용과 내가 세운 실험 가설을 나눠 기록 |
| 연결 · 다음 검증 | 담당 랩과 기존 실험 또는 후보 링크, 비교할 입력·관측값·판정 조건 |
| 실험 상태 | 후보 / 설계 / 로컬 검증 / 런타임 검증. 실행한 환경·입력과 증적을 함께 기록 |

공식 프로그램에 소개된 세션은 발표 본문이 확보되기 전까지 그 범위로 기록합니다. 공개 기록은 가상 환경과 공개 가능한 자료만 사용합니다.
