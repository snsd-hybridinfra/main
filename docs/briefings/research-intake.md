# 브리핑·컨소시엄·세미나 기록

자료는 **어디에서 나온 정보인지**에 따라 아래 세 분류 중 하나에 기록합니다. 여러 분류에 걸친 주제는 원문을 가장 잘 설명하는 곳에 한 번 기록하고 관련 항목을 연결합니다. 운영 질문이 생기면 [실험 후보](../experiment-backlog.md) 또는 해당 랩의 기존 실험을 연결합니다.

#### guardscope

|---|---|
| 발표일 · 자료 유형 | 2026-11-11, arXiv 프리프린트 v1. 2026-11-16 확인. |
| 핵심 발견 | 게이트웨이의 기록만으로는 에이전트의 모든 실행 경로를 확인하기 어렵습니다. 연구진은 도구 호출이나 직접 네트워크 연결을 포함한 15개 경로를 정의하고, 제어 지점의 로그와 커널 관측을 대조하는 방법을 제시했습니다. |

| 원문 · 코드 | [guardscope 논문](https://arxiv.org/abs/2611.15223) · [연구 코드](https://github.com/VulcanLab/guardscope) |

#### MCP gzip 도구의 NAT64 주소 검사

| 항목 | 기록 |
|---|---|
| 발표일 · 자료 유형 | 2026-11-18, 공식 보안 분석 GHSA-38j4-j742-j7r3. 11-20 확인. |
| 발견 · 실험 | server-everything의 gzip 도구가 NAT64 `64:ff9b::/96` 안의 IPv4를 검사하지 않았습니다. 제보자의 모의 DNS·fetch 시험에서 수정 후 7/7 및 기존 41/41 검사가 통과했습니다. |
| 영향 · 수정 | 권고의 영향 범위는 `<2.3.1` 및 날짜 버전 `2026.1.14~2026.8.31`, 수정은 `2.3.1`입니다. |
| 한계 · 재현 자료 | 실제 내부망 접근에는 NAT64/DNS64 경로가 필요합니다. 제보자는 종단 간 연결을 실증하지 못했습니다. 전체 제보 시험 코드는 요청 시 제공한다고 기록했고 [수정 PR](https://github.com/modelcontextprotocol/servers/pull/5583)은 공개됐습니다. |
| 랩 적용 · 로컬 검증 | 사설·링크 로컬 IPv4를 내장한 합성 NAT64 URL을 등록 API와 호출 정책에 각각 넣어 4건을 거부했습니다. 기존 단일 호스트 허용 목록을 검증하며, IPv4 내장 주소 분류·변환기의 동작은 후속 검증 범위입니다. |
| 원문 | [공식 권고](https://github.com/modelcontextprotocol/servers/security/advisories/GHSA-38j4-j742-j7r3) |

2026-11-20 검증에서는 MCP 회귀 67/67건이 통과했습니다. 기존 47건의 출력이 보존됐고, 신규 20건은 공급자 바인딩·회수·복구 관련 16건과 NAT64 URL 거부 4건입니다. 실행 범위와 명령은 [랩 기록](../../labs/role-groups/04-security-trust/experiments/ai-agent-security/README.md#2026-11-20-공급자-바인딩과-nat64-회귀)에서 확인합니다.

## 컨소시엄

표준화 단체·산업 협의체의 규격, 작업 초안, 상호운용성 자료입니다. 단체명, 문서 번호, 버전과 상태(초안·발행 규격·구현 보고서), 확인한 조항을 기록합니다. 상호운용성을 주장하는 자료는 참여 구현과 시험 조건을 함께 남깁니다.

공식 원문을 확보한 첫 항목부터 추가합니다. 검토 주제는 멀티벤더 EVPN의 경계 동작과 AIDC 패브릭의 혼잡·텔레메트리입니다.

## 새 항목 기록 양식

| 필드 | 기록 내용 |
|---|---|
| 제목 · 분류 | 같은 주제의 기존 항목이 있으면 해당 항목에 이어서 기록 |
| 원문 · 날짜 | 공식 URL, 발표자 또는 기관, 발행·발표일, 실제 확인일 |
| 확인 범위 | 프로그램 안내 / 원문 본문 / 발표 자료 / 재확인 대기. 필요한 경우 페이지·시각·버전 기재 |
| 확인한 내용 · 해석 | 출처가 설명한 내용과 내가 세운 실험 가설을 나눠 기록 |
| 연결 · 다음 검증 | 담당 랩과 기존 실험 또는 후보 링크, 비교할 입력·관측값·판정 조건 |
| 실험 상태 | 후보 / 설계 / 로컬 검증 / 런타임 검증. 실행한 환경·입력과 증적을 함께 기록 |

공식 프로그램에 소개된 세션은 발표 본문이 확보되기 전까지 그 범위로 기록합니다. 공개 기록은 가상 환경과 공개 가능한 자료만 사용합니다.
