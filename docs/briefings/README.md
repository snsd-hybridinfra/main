## 기록 기준

- 같은 기술의 후속 보도는 기존 주제와 랩에 합친다.
- 브리핑 날짜, 원문 발행일, 사건일, 이번 확인일을 구분한다.
- **공식 자료 확인 / 기존 기록 종합 / 재확인 대기**는 출처 상태다.
- **계획 / 설계 / 로컬 검증 / 런타임 검증**은 실습 상태다. 출처 확인만으로 실습 상태를 올리지 않는다.
- 신규 실습 실행은 이번 정리의 범위에 포함하지 않았다. 기존 14개 랩의 실행 상태는 각 README와 증적을 따른다.
- 고객사 구성·주소·장비 식별자·계정·원시 운영 로그를 학습 자료에 포함하지 않는다.

## 이후 브리핑을 추가할 때

한 항목에 `브리핑 날짜 → 원문·발행일 → 확인한 사실 → 내 해석 → 연결 랩·상태 → 다음 검증`을 남긴다. 한국·해외 구분은 유지하되, 누적 정리에서는 같은 사건의 반복을 제거한다. 하루 기사 수와 누적 기술 주제 수를 혼동하지 않는다.
