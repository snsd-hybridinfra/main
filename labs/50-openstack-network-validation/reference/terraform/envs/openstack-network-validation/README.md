# OpenStack Network Validation Environment

This directory composes the local OpenStack network module with non-production example values. The external network name remains an explicit placeholder and the DNS address uses the documentation-only TEST-NET range.

Do not place credentials, authentication URLs, project or tenant identifiers, real variable files, state, `clouds.yaml`, openrc files, backend configuration, or account-specific values here. retired-numbered-case does not authenticate to OpenStack and does not run Terraform initialization, provider validation, planning, or apply operations.
