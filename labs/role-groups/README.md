# 운영 역할 랩

저장소 루트에서 `python3 tools/run_role.py all`로 각 역할의 대표 사례를 실행합니다. 번호 랩의 코드·설계·기존 증적은 각 역할 페이지에서 찾아볼 수 있습니다.

| 역할 랩 | 입력과 확인 항목 | 번호 랩 |
|---|---|---:|
| [Network Fabric](01-network-fabric/README.md) | 경로 모델, FRR/EOS 설정 재생성, NetBox 등록 계획 | 8 |
| [Cloud Foundations](02-cloud-foundation/README.md) | 공급자별 주소 예제, 서브넷 배치 및 주소 중복 | 9 |
| [Platform Delivery](03-platform-delivery/README.md) | 카탈로그, 실행 프로파일 및 블루프린트 상태 | 9 |
| [Security & Trust](04-security-trust/README.md) | IAM 정책, 신뢰 관계 및 허용·거부 판정 | 9 |
| [Observability & SRE](05-observability-sre/README.md) | 합성 메트릭·관제 지표·장애 로그 | 5 |
| [Change Automation](06-change-automation/README.md) | 읽기 정합성·변경 정책·설정 비교·원복 | 7 |
| [Recovery & DR](07-recovery-dr/README.md) | 백업 스냅샷·장애 주입·격리 복원 | 4 |

대표 사례의 검증 결과는 해당 사례에 적용됩니다. 번호 랩별 출처 상태는 역할 페이지의 표와 [카탈로그](manifest.json)에서 확인합니다. [대표 사례 실행 결과](evidence/2026-11-12.json) · [역할 구성과 연결 범위](../../docs/role-consolidation-plan.md)
