# Kubernetes RBAC Baseline Examples

All files in this directory are NON-PRODUCTION EXAMPLES for local static validation only.

- Namespace: `snsd-example`
- Dedicated application and monitoring ServiceAccounts
- Namespace-scoped Roles and RoleBindings
- No Secret resources, token material, ClusterRoleBinding, cluster-admin, wildcard permission, kubeconfig, or cluster endpoint

Do not apply these examples to a cluster without a separate implementation review.
