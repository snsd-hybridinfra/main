# OpenStack Network Module

This module is a reviewable, non-production Terraform definition for retired-numbered-case. It defines a private network, subnet, external network reference, router, router interface, baseline security group, and one management rule placeholder.

The module contains no provider credentials, provider configuration, backend configuration, public IP resource, project identifiers, authentication URL, or production values. retired-numbered-case does not run `terraform init`, `validate`, `plan`, or `apply`. Provider validation belongs to retired-numbered-case, and security group validation belongs to retired-numbered-case.
