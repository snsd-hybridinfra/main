
# ZT-ARC-001 Advanced Target Architecture

ZT-ARC-001 establishes the authoritative post-Phase-1 architecture, capability selection, portability contracts, phase gates, Golden Path, Advanced acceptance model, future Optimal interfaces, and runbook framework.

- Package type: `ARCHITECTURE_GOVERNANCE`
- Phase: `CROSS_PHASE_GOVERNANCE`
- Implementation: `DESIGN_ONLY`
- Local validation: `LOCAL_VALIDATED`
- Runtime validation: `NOT_VALIDATED`
- Current maturity: `UNASSESSED`
- Authority: `AUTHORITATIVE`

It deploys no application or infrastructure, modifies no monitoring configuration, and changes no current capability assessment. `target_maturity: ADVANCED` is a future target, not a current maturity result. `optimal_ready: true` is a repository-local architectural property and not an official maturity level. The target-architecture authority is `docs/zero-trust/target-architecture/`; the operational runbook authority is `docs/runbooks/`.
