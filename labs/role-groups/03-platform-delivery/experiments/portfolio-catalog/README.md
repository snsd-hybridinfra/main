# 운영 실험 카탈로그 UI

7개 랩의 실험을 검색하고 소속 랩과 검증 상태로 좁혀봅니다. 브리핑·컨소시엄·세미나 기록과 후속 실험 후보로 이동할 수 있습니다. [카탈로그 매니페스트](../../../manifest.json)를 읽어 실험 목록과 상태를 표시합니다.

## 실행

저장소 루트에서 다음 명령을 실행한 뒤 브라우저에서 엽니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

[로컬 카탈로그 열기](http://127.0.0.1:8000/labs/role-groups/03-platform-delivery/experiments/portfolio-catalog/web/)

## 확인

1. 초기 화면에서 7개 랩과 등록된 실험 수를 확인합니다.
2. `BGP`로 검색한 후 네트워크 패브릭과 기존 로컬 검증 상태를 함께 선택합니다.
3. 검색어에 없는 값을 넣고 결과 없음 안내를 확인합니다.
4. 브리핑, 컨소시엄, 세미나, 실험 후보 링크를 엽니다.

로컬에서 읽기 전용으로 사용하는 정적 UI입니다. 문서 링크는 저장소의 Markdown 원문을 엽니다. 실험 추가와 상태 변경은 Git의 매니페스트와 해당 랩 README에서 관리합니다.

로컬 검증은 검색·필터·빈 결과·요청 실패 처리의 JavaScript 동작과 카탈로그 링크를 대상으로 했습니다. 실제 브라우저 화면과 반응형 레이아웃은 위 절차로 확인합니다.
